# Mein Kalorientracker

Private PWA für iPhone/iPad.

## GitHub Pages aktivieren
Repository > Settings > Pages > Deploy from a branch > main > /(root) > Save

Danach die veröffentlichte URL auf dem iPhone in Safari öffnen:
Teilen > Zum Home-Bildschirm

Die erfassten Daten werden lokal im Browser/PWA-Speicher des iPhones gespeichert.
CSV- und JSON-Backups können direkt aus der App heruntergeladen werden.
